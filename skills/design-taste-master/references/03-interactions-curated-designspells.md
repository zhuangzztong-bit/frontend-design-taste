# 03 · 设计交互与微动效参考库（Curated & Design Spells 真实案例拆解）

> 来源实测：`https://www.curated.design`（高质量实时交互网站库）与 `https://designspells.com`（顶级产品微交互与情感细节库）。  
> 适用场景：动效设计、悬停/按压反馈、页面与组件过渡、空状态/更新引导、品牌彩蛋。

## 一、Design Spells 5 个真实微交互标杆

### 1. Dia 浏览器 — 滑动长按展开历史栈（`Desktop / Interaction / Motion`）
- **机制**：在网页浏览执行“滑动并长按”手势时，不生硬立即跳回上一页，而是平滑展开当前标签页的历史记录卡片列表（含站点小图标与标题），悬停高亮选中目标，松手一步直达。
- **前端启发**：将高频但机械的重复点击（如多次后退、多步撤销）升级为**可预览、可连续选点的物理手势/长按菜单**。

### 2. One Year — 日期高亮原地 Morph 形变为搜索栏（`Mobile / Transition / Morph`）
- **机制**：顶部淡紫玻璃质感的当前日期胶囊在触发搜索时，通过**共享元素形变（Shared Element Morph）**直接横向拉伸为顶部半透明搜索栏（左侧出现放大镜、右侧出现 `×`），无需整页跳转。
- **前端启发**：使用 CSS `view-transition-name` 或 Framer Motion `layoutId`，让按钮→输入框、卡片→详情弹窗保持**空间位置连续性**，保护用户心流。

### 3. Instagram — 长按点赞触发 Super Like 粒子与实时计数（`Animation / Button / Confetti`）
- **机制**：长按爱心按钮时，按钮放大并连续向上发射渐变粒子，同时跳出实时累加数字（`1 ❤️`）与底部氛围光晕。
- **前端启发**：**交互时长 = 情感/确认强度**。在点赞、收藏、删除确认等场景，可用短按轻反馈 + 长按递进反馈，赋予操作温度与防误触能力。

### 4. Notion Calendar — 版本更新引导流的小兔子魔法棒微动画（`Animation / Occasion`）
- **机制**：在 `Something new is here` 弹窗的 `Next` 按钮上方嵌入极简黑白线条小兔子 + 蓝色魔法棒轻点微动画，与品牌插画风格高度统一。
- **前端启发**：空状态（Empty State）、404、版本更新（What's New）是最容易消除工具冰冷感的位置；用 **1 个克制的 SVG 线条微动画**替代千篇一律的灰色图标。

### 5. Google — 搜索关键词触发文化彩蛋（`Easter Egg / Occasion`）
- **机制**：搜索 `"Robert Pattinson"` 时触发呼应 007 经典台词 `"Shaken, not stirred"` 的专属页面彩蛋动效。
- **前端启发**：彩蛋必须遵守**零干扰原则**——不影响核心任务完成，只在特定触发词、快捷键或边缘探索时出现。

## 二、Curated 真实高水准交互站点观察

从 Curated 首页与详情页实测收录的 6 个代表站点中提炼出的现代 Web 交互规律：
1. **Santal**（建筑与室内设计工作室）：极度克制的滚动节奏与高精度图片揭示（clip-path / 缓入），绝不做廉价弹跳动画。
2. **Subframe**（连接可视化设计与代码的 AI 设计工具）：交互演示直接让用户在页面内实时拖拽/切换组件属性，**把产品核心体验前置为可玩沙盒**。
3. **Aren**（AI 医疗护理软件）：用清晰的微动效展示数据流与状态切换，配色温暖专业，彻底摆脱“暗黑赛博 AI”刻板印象。
4. **Aonnoy Sengupta Portfolio / Vendredi Society / VS Goods**：善用精细光标态（custom cursor 仅在作品卡片悬停时切换为 `View` / `Drag` 胶囊）、柔和的磁吸按钮（magnetic hover）与基于物理弹簧（spring）而非线性 `linear` 的缓动曲线。

## 三、微交互前端实现规范
- **推荐缓动曲线**：
  - 常规 UI 状态切换：`cubic-bezier(0.22, 1, 0.36, 1)`（快出慢收，干净利落，180ms~260ms）
  - 弹性微反馈（按钮/胶囊形变）：`cubic-bezier(0.34, 1.56, 0.64, 1)`（极轻微过冲，220ms~320ms）
- **微交互红线**：
  - 严禁给所有卡片加无意义的 `hover:scale-105 + shadow-2xl + glow`（典型 AI 廉价感）。
  - 优先使用**描边变亮、背景微移 1~2px、箭头右移 `translate-x-0.5`、下划线从左向右展开**等克制反馈。
  - 必须尊重 `@media (prefers-reduced-motion: reduce)`。
